# VLM4Cluster Leaderboard

[Open the interactive leaderboard](https://vlm4cluster.github.io).

Published static website for the [VLM4Cluster benchmark](https://github.com/hyw1008/VLM4Cluster).

GitHub Pages serves this repository from the root of `main`. Dataset routes are
provided as HTML entry points so direct links and browser refreshes work.
The bundled client includes the recorded benchmark results; no backend is required.

Third-party JavaScript licenses are included in `THIRD-PARTY-LICENSES.txt`.
